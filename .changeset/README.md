# Changesets

This repository uses [Changesets](https://github.com/changesets/changesets) for versioning and publishing packages.

## How to add a changeset

Run the following command from the root of the repository:

```bash
npm run changeset
```

Follow the prompts to select which package(s) were modified, choose whether the change is a `major`, `minor`, or `patch`, and provide a summary of the change.
